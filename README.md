# CitySwiper 🌆✨
### Твой персональный фуд-радар и гид по лучшим заведениям города

[![Live Demo](https://img.shields.io/badge/Demo-artsmile.github.io%2FCitySwiper-2563eb?style=for-the-badge&logo=google-chrome&logoColor=white)](https://artsmile.github.io/CitySwiper/)
[![License](https://img.shields.io/badge/License-MIT-emerald?style=for-the-badge)](LICENSE)

> **Забудьте о скучных списках и бесконечных вкладках на картах.**  
> CitySwiper превращает выбор ресторана, бара или кофейни в увлекательную, лёгкую и тактильную игру в формате swipe-карточек.

---

## 🍽 Знакомая ситуация?

Пятничный вечер, романтическое свидание или поездка в новый город:
- Открыто 15 вкладок в браузере и 4 приложения с картами.
- Отзывы противоречивые, фото разрозненные, средний чек непонятен.
- Пока выбирали, куда пойти — аппетит пропал, а столики уже забронированы.

**CitySwiper решает эту проблему за 30 секунд.** Никакой информационной перегрузки: перед вами только одно конкретное заведение с сочными фотографиями, честным рейтингом, атмосферой и статусом работы. Одно движение пальца — и решение принято.

---

## ⚡️ Как это работает

Вся магия взаимодействия вдохновлена механикой дейтинг-приложений, но адаптирована под гастрономические открытия:

- 👉 **Свайп вправо** — *«Хочу пойти!»* Заведение мгновенно отправляется в список ваших планов.
- 👈 **Свайп влево** — *«Не сейчас»*. Пропускаем и смотрим следующий вариант.
- 👆 **Свайп вверх** — *«В Избранное»*. Для любимых жемчужин и проверенных мест, куда хочется возвращаться снова и снова.
- 👇 **Свайп вниз** — *«Детали»*. Полный адрес, график работы, ценовой диапазон и навигация.

## 💎 Особенности и детали

### 📳 Тактильный отклик (Haptic Feedback)
Приложение оживает прямо в ваших руках: физический движок с естественной инерцией и нежная вибрация при захвате и сбросе карточки дарят ощущение взаимодействия с реальными премиальными глянцевыми открытками.

### 🖼 Живая галерея интерьеров и блюд
У каждого места — кинематографичная карусель фотографий высокого разрешения. Листайте снимки мягким тапом с бережными микроанимациями перехода.

### 🛎 Бронирование в один клик («Find a table»)
Если заведение поддерживает онлайн-бронирование через Google, на карточке сразу появится кнопка **«Find a table»**. А кнопка **«Open in Maps»** мгновенно проложит маршрут до дверей.

### 🔍 Умные и лаконичные фильтры
Ищете уютный ужин прямо сейчас? В сохранённых местах доступна удобная панель быстрых фильтров:
- 🟢 **Открыто сейчас** — только заведения с открытыми дверями на текущий момент.
- 💶 **Ценовой диапазон** — от бюджетных стритфуд-спотов до высокой кухни.
- 📍 **Расстояние от центра** — наглядный слайдер радиуса для вечерней прогулки.

### 🎨 Эстетика Weightless Porcelain & Manrope
Никакой серости и шаблонности. Интерфейс вдохновлён премиальным стилем Apple: легкое матовое стекло (frosted glass), сглаженные концентрические радиусы, деликатные тени и утонченная типографика на базе современного гротеска **Manrope**.

### 🌍 Города мира в кармане
Легко переключайтесь между городами и странами: от Парижа и Рима до Вильнюса, Варшавы, Барселоны и Тбилиси.

## 🛠 Локальный запуск (для разработчиков)

Если вы хотите запустить проект локально или добавить свои фичи:

```bash
# Клонировать репозиторий
git clone https://github.com/ArtSmile/CitySwiper.git
cd CitySwiper

# Установить зависимости
npm install

# Запустить локальный сервер для разработки
npm run dev

# Собрать автономный production-билд
npm run build
```
